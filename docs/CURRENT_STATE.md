## 3. 已有科研流程

按需澄清 → 设计并确认路线 → 文献或数据处理 → 证据/结果综合 → 报告 → 独立审查 → 交付与登记。

- 信息充分不强制问答；已有数据未上传时先采纳路线再绑定文件，不反复询问上传时机。实际阶段依路线变化。
- 文献：检索去重、相关性初筛、用户确认材料、导入索引、证据综合、按需全文核验。
- 数据：最多 16 份 CSV/TSV/XLSX，不强制业务字段模板；支持 Python 环境、计算、图表、代码与复现产物。
- AI 自写 Python 可修复错误最多连续自动修复 3 次；研究方法或约定实质变化仍需确认。
- 完成未登记时支持自然语言问答与返修协商；用户确认提案后重跑依赖范围，已登记版本保持冻结。
- 独立审查跟踪跨轮问题；报告、引用、计算和审查绑定具体快照。系统通过不等于科学正确或达到发表标准。
- 消息与卡片统一时间线，工具默认折叠。文献发现按任务组织，删除/归档任务清理关联发现记录，但不等于物理删除知识库或已登记产物。

## 4. 文献与证据边界

- 六类来源：PubMed、Europe PMC、Crossref、OpenAlex、Semantic Scholar、arXiv。默认 1 条、最多 2 条完整检索式，每式每源只取首页最多 20 条，不自动翻页；去重后 AI 初筛。
- 区分直接相关、待核验、背景与排除；建议导入不等于已完成全文评估。推荐及导入最多 100 篇。当前策略适合范围受限综述，不保证系统综述的全面性。
- 自动导入优先摘要，缺摘要才尝试开放全文；允许的获取失败可降级题录并留警告。显式全文、安全/内容校验和本地保存错误不能冒充降级成功。
- 题录不能支持效果结论，PDF 不代表通读全文。来源失败与证据不足分开记录，不以扩大检索掩盖 429。
- 综合优先整体处理，材料过大才按字节分组；保留上下文预算，不机械逐篇请求 AI。
- 全文工具返回有限相关片段并保存完整可解析材料；新任务综合阶段由宿主重新索引、检索新引用后再综合，工具片段本身不是签发引用。仍不保证全文通读、OCR 或所有关键段落均命中。
- 报告与历史产物各用自己的冻结引用；内部 `[K-...]` 在引用感知界面显示为可点击编号，不借用其他版本/任务引用。
- 证据摘录仅兼容空白与词内 Unicode 连字符排版差异：同引用内唯一匹配后保存精确原文，继续严格校验，不改数字、语义或来源快照；已用真实失败输出离线回放通过，未自动重跑用户任务。
- 文献发现和科研产物不自动跨任务复用；知识库按本任务和明确项目共享范围使用。
- 原生 HTTP 使用浏览器 UA/TLS/H2 适配，不保证解决限流。应用级网络已接入模型、搜索、文献、依赖、Skills、MCP 和浏览器：模块 → 全局 → 直连，支持强制直连；不支持代理认证。长期子进程需重启后采用新设置，不是 OS 透明代理。详见 [NETWORK_BROWSER.md](NETWORK_BROWSER.md)。
