# SciAide v1.0.1

本次发布汇总科研路线、文献证据、数据分析、审查返修与引用展示的改进。

## 主要功能

- 自由对话与科研模式：按需澄清、确认研究路线、时间线执行、暂停与恢复。
- 六类文献来源适配，完整检索式首页检索、去重初筛、人工选材、摘要优先导入及可信证据综合。
- 多文件数据输入、项目 Python 环境与代码执行；可修复 Python 错误最多连续自动修复 3 次。
- 独立审查逐项跟踪问题；登记前通过自然语言协商返修，确认后重跑受影响阶段。
- 报告、历史交付和产物预览显示可点击引用编号，查看冻结原文及来源；保留版本与审计。
- 项目知识库、MCP、311 个默认 Skill、科研产物来源链及 DOCX/PDF 导出。
- 优化工具协议、上下文处理及页面更新；统一版本标识为 1.0.1，更新 README 和三张功能截图。

## 下载与升级

- `SciAide.exe`：Windows x64 桌面程序，需要 WebView2 Runtime。不是安装包；用户需自行配置模型 API，分析任务按需配置 Python。
- `SciAide.exe.sha256`：程序 SHA256 校验文件。
- 升级前退出旧程序，建议先导出重要项目归档。历史任务不自动改写冻结契约，验证新流程建议新建任务。

## 已知边界

- AI 审查不替代专家核查；摘要证据不等于全文系统评价，不能保证研究结论正确。
- 文献服务可能限流或无法获取全文，不保证固定检索耗时。全文新增证据的引用再签发闭环仍待完善。
- 尚未完成代码签名、安装升级加固及长时间压力验证；本地执行不是强安全沙箱。
- 全仓门禁尚有两项已知旧迁移夹具失败（缺少 `deleted_at`），未将本次定向验证宣称为全仓通过。详情见 `docs/CURRENT_STATE.md`。
