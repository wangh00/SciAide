# SciAide v1.0.3

本次发布保存 v1.0.2 之后已完成的科研执行、证据引用、审查返修及报告界面优化，保留现有聊天瀑布流和用户确认执行的边界。

## 优化前 / 优化后

- **证据与引用**：修复核读来源被保存层拒绝、同一原文块不同来源快照冲突以及反复采证不收敛的问题。保留真实来源、冻结原文与历史引用，不用放宽来源校验掩盖错误。
- **审查与返修**：修复审查输入投影、原目标和完整意见传递及并发恢复问题；恢复按建议直接返修，删除重复的“让 AI 整理返修方案”。引用补选明确显示原选、新增与审查提及引用，用户确认后才继续，不自动全选或重跑。
- **连续研究**：登记前可在原对话补证、上传单文件方法参考或更换数据；确认方案后局部重算并保留旧结果。新增阶段记录读取、执行源码复制与下载以及多类型材料处理。
- **报告界面**：报告、分析、研究设计、路线选择、人工检查和返修确认共用科研内容卡底座；返修范围、文件身份及完整要求分层展示。报告阅读增加章节导航、展开阅读、置信与证据边界说明，生成文件集中展示。
- **模型与工具恢复**：改进 SSE 流错误、可重试并发错误及工具拒绝的诊断与恢复；不自动复活取消的任务，不扩大旧冻结路线权限。
- **测试材料**：附 RF/XGBoost/CatBoost 文献比较、UCI Wine Quality 数据分析、Ridge 方法续做案例包及独立核对脚本。

## 下载与升级

- `SciAide.exe`：Windows x64 桌面程序，需要 Microsoft Edge WebView2 Runtime；模型 API 和项目 Python 仍需用户自行配置。
- `SciAide.exe.sha256`：对应程序的 SHA256 校验文件。
- `research-cases.zip`：上述案例的数据、输入流程与人工核对参考，不是模型验收证明。论文原件及全文提取稿不公开再分发，包内提供原始来源、版本哈希和下载核验脚本；已准备的本地原件保持不动。
- 升级前退出旧程序，建议先导出重要项目备份。已有任务的界面优化无需新建任务；新路线行为应在隔离新任务中验证，历史冻结结果不自动改写。

## 验证边界与下一步

- 发布前执行全量 Go 测试与 vet、前端回归与类型检查、离线浏览器交互回放及 Windows amd64 前后端构建；具体结果见科研开发文档的发布检查点。
- 自动化包含受控模型、临时 SQLite 和真实任务只读捕获回放；用户已有真实案例记录及独立数据复算与自动化分开记录。**不宣称新版商业模型与原生桌面完整闭环已验收，也不保证科研审查必然通过。**
- **尚未实现**：科研模式自然对话开局、多轮需求协商、产物后完全自由对话、左侧动态本轮路线及“历史路线”入口。这是后续开发方向，不是本版新增功能。
- AI 审查不替代专家核查；摘要不等于全文，来源与服务可能限流。尚无代码签名或安装更新加固，本地执行不是强安全沙箱。
- 发布前生产依赖审计报告 KaTeX 相关 4 个 low 条目（同一公告 [GHSA-238p-pmpm-9mq7](https://github.com/advisories/GHSA-238p-pmpm-9mq7)，原型污染下可能绕过 trust 限制）。本版保留既有 `trust: false` 等渲染限制，但不将其视为彻底修复；依赖升级需另做兼容与公式安全回归，审计未通过。
