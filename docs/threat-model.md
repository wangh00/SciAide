# 安全边界与残余风险

更新：2026-10-15。适用当前开发工作树，替代旧 P0–P7 按阶段追加的威胁模型。本文描述实现边界，不是渗透测试认证或“不会出错”的保证。

## 保护资产与信任边界

保护对象包括模型/MCP 凭据、未公开论文和数据、Workspace 文件、研究结论与引用、执行记录和本机资源。

用户材料、网页、LLM 输出、MCP 描述/结果、Skill 正文/脚本、模型元数据及归档均是不可信输入。它们可以提供研究信息，不能改变工具权限或证明自己的真实性。

```text
WebView → Wails Facade → Application / Policy → Adapter → 文件 / 进程 / 网络
```

UI 展示、模型文字和工具发现结果都不是授权来源。重要执行身份与状态以宿主持久化记录为准。

## 当前控制

### 凭据、日志与模型协议

- Windows 使用 Credential Manager，SQLite 保存 secret reference；Facade 不提供明文读回接口。非 Windows 不以明文文件回退冒充等价凭据实现。
- 模型自定义 Header 拒绝敏感名称与 CRLF；错误主文案与有界、脱敏诊断分开，不把原始服务端正文直接带入聊天或下一轮上下文。
- 模型 API、Embedding、MCP 和识图配置不编译进 EXE；项目归档不携带可用密钥。
- Provider 原生 turn 独立保存；原始 thinking、signature 和 encrypted payload 不进入 UI。明确的安全摘要、用量与状态投影不冒充完整内部推理。
- checkpoint 原文不删除，哈希和边界用来校验保存完整性；摘要仍可能遗漏科学细节。

### 工具与审批

- Tool Registry 固定名称、Schema、风险、权限与幂等性；注册/执行均校验，模型不能自己降低风险或替换定义。
- 普通聊天 Plan 对宿主限定的低风险幂等 Workspace 读取、MCP 状态/工具发现有只读放行，其余按调用确认；Workflow 使用冻结契约和其权限评估路径。Full Access 跳过审批不等于越过任务/路径/Schema 边界。
- 执行前复核 Run、Project、任务归属及契约；超时、取消、并发保护、panic 隔离和结果大小限制仍生效。
- 未知名称和非法参数保存为失败结果供模型纠正，不执行猜测的工具。资源 ID 与操作只适用于签发范围；目录、枚举或发现不能授权跨任务读取。
- 重复点击、过期回答、迟到工具结果不能覆盖终态；非幂等结果未知时不得静默重放。

### 文件、附件与研究数据

- 普通 Workspace 工具拒绝绝对路径、越界、保留私有目录及逃逸链接；使用 PathGuard/`os.Root` 等路径边界。
- 科研执行从持久绑定确定任务根，不因查询失败回退到整个项目 Workspace；同一任务与显式项目共享资源分别处理。
- 附件在项目内暂存、校验、原子发布；OOXML/归档检查路径、重复条目、数量、展开大小与异常压缩比，不执行宏或公式。
- 知识库只索引显式成员。移出知识库不删除原件、历史消息或产物，也不让其他任务自动取得权限。
- 在线候选、网页文字和模型生成的 `[K-...]` 不能直接取得可信引用身份。正式引用复核来源、原文快照、作用域和哈希；哈希不证明科研主张正确。
- 新报告附录只投影已保存筛选与精确书目身份，不猜作者/DOI、不推断试验同一性、不自动修科学正文。

### MCP、Skill 与网络

- MCP 配置/启用/信任由用户显式操作；stdio 不拼接 Shell，远程连接限制协议与地址形式，凭据与普通配置分开。
- MCP 工具不能覆盖 builtin，继续走统一工具管道；发现 Resource/Prompt 不等于自动向模型注入或执行。
- Skill 目录、正文及资源都不可信；加载保存包与内容快照，资源访问受路径/哈希限制。物化脚本并不执行，正式执行和依赖安装各走原有权限链。
- 压缩 Skill 只改变内嵌资源存储，不改变信任等级或删除许可证。
- 代理失败不偷偷直连；浏览器 Cookie 不给模型、不进入普通工具审计。不同 HTTP、浏览器、MCP 和子进程的出站能力不应被混称“全局网络沙箱”。具体限制见 [网络文档](NETWORK_BROWSER.md)。

### 本地执行不是强安全沙箱

- Shell、一次性 Python、Kernel 获准后具有当前用户权限，能够主动访问外部路径或联网。宿主路径检查只约束声明的输入输出，不能隔离恶意代码。
- 子进程使用有限环境，不注入应用模型/MCP 密钥；PowerShell 不读取 Profile。但允许的用户目录和本机资源仍可能包含敏感数据。
- Windows 本地执行与 Kernel 使用 Job Object 约束进程树生命周期；stdout/stderr 持续排空并保留有界预览与审计，取消、超时和退出进行清理。
- Kernel 使用项目环境、串行执行、输入复核及声明输出回滚，默认进程树内存预算 1 GiB；这不提供 CPU、文件系统或网络强隔离。
- 环境安装可能执行第三方包代码，应审阅依赖来源；Skill 或模型不能把依赖可用性等同于自动安装授权。
- 复现哈希证明记录一致，不能证明统计方法适当、远程数据可复现或科学结论正确。

### 持久化、产物和恢复

- 核心消息/运行终态、工具结果和必要 Provider 状态保存失败时不伪装完成；辅助遥测和核心提交有不同处理，不能一句“所有写失败都可忽略”。
- Artifact 版本与来源快照不可变；导出绑定源版本、格式与生成器，发布和下载避免覆盖既有文件。
- 项目归档只包含明确枚举的项目对象和无密钥关系；隔离校验、ID 重映射与原子发布，恢复失败不暴露半项目。
- UI 快照不重复传输无展示用途的内部 prompt；renderer 恢复有条件、有次数边界，不因页面刷新自动重跑研究。

## 仍需解决或继续验收

| 风险 | 当前界限 / 后续工作 |
| --- | --- |
| Prompt 注入、模型误判 | 权限隔离不保证模型不受材料误导；仍需来源核查、短自然输入和真实任务评测 |
| 科学结论与重复返修 | 格式校验与 AI 审查不是专家认证；需要独立数值/来源核对及多轮收敛验证 |
| 超长上下文 | 去重和 checkpoint 不能让无限独特材料进入窗口；材料按需读取仍需扩展 |
| 内存、白屏与长时运行 | 已有缓存/视图减负和 renderer 恢复；真实 OOM、数小时驻留及跨任务压力仍待验收 |
| 网络与 SSRF | 网页/文献有各自出站检查；浏览器子请求、可信代理、远程 MCP DNS/重定向边界仍需逐条审计，不宣称统一 OS 网络隔离 |
| MCP 子进程 | 不能把本地执行器的 Job Object 保证自动套用到所有 MCP server；具体生命周期和进程树仍需专项核对 |
| 供应链 | Skill/包哈希不等于发布者签名；第三方工具、Python 包与依赖升级需要独立审阅 |
| 多进程共享数据根 | 日志轮转与写入边界不能视为多进程协调锁；不把多个开发实例同时指向正式数据根，单实例与并发写入仍需专项核查 |
| 发布 | 历史 v1.0.3 记录了 KaTeX low 审计项；当前是否仍存在要重跑审计，不把历史结果当当前通过或失败。代码签名、安装/更新与 SBOM 加固尚未完成 |
| 跨平台 | 当前正式构建目标为 Windows x64，不把其他平台适配骨架当发布验收 |

## 验证要求

权限、资源、归档和新运行时变更至少测试跨项目/任务 ID、路径逃逸、取消、重复/迟到提交、重启、损坏快照和缺失凭据。采用临时数据库和受控服务；故障注入仅在隔离实例进行。测试来源及当前通过情况见 [开发进度](PROGRESS.md)，不能用一次夹具通过宣称所有残余风险关闭。
