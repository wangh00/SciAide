# 应用网络与项目浏览器

## 使用

左下角“设置”集中模型/API、联网搜索 Key、Skills、MCP、网络与代理。默认直连，不修改操作系统代理。搜索页只显示当前网络状态并提供跳转，不再单独编辑代理；旧 `websearch/proxy` 记录不再读取，已有旧专用代理需在网络页的“联网搜索与网页读取”重新设置。

网络优先级：对应模块覆盖 → 全局 → 直连。模块支持继承、强制直连、自定义代理；HTTP、HTTPS、SOCKS5，当前不支持代理账号密码。保存有版本检查，防止过期窗口覆盖新设置。代理失败不自动直连。

覆盖模型/向量模型、搜索/网页读取、文献检索/下载、Python/依赖安装、Skill Git 下载、MCP、浏览器访问。HTTP 客户端在下一次请求刷新代理；已开始的下载/浏览器会话固定配置，配置变化时拒绝复用其 Cookie。已运行 Python Kernel、MCP 子进程需重启才能获得新环境。第三方程序忽略代理变量或自行创建网络连接时不能保证接管；这不是系统透明代理。

## 项目浏览器

当前项目 Python 环境 → “配置浏览器环境” → 安装。必须是 Workspace 托管 Python，不修改外部/旧式环境。

- Python 包：项目 `.sciaide/python`，锁定 `cloakbrowser[geoip]==0.5.9`。
- Chrome、GeoIP、运行脚本、浏览器缓存与临时目录：项目 `.sciaide/browser`。
- 安装走“Python 与依赖安装”代理；主动网页工具走“浏览器访问”代理；文献质询复用**该次文献下载**的代理，不能改用浏览器模块的另一个出口。
- 原 `cloudflare/solve.py` 直接嵌入，质询算法不修改。外围 bridge 处理目录、代理、出口核验、私有结果与取消；自动更新关闭，更新通过显式安装/修复完成。
- 同项目不允许并发浏览器操作，跨项目排队可取消；状态查看不抢占运行与取消句柄。Windows 取消通过 Job Object 回收子进程树。

安装后自由对话可见 `browser_open`；新科研路线包含其冻结工具定义。旧冻结路线不强行扩充，新工具建议新开任务测试。已有任务的代理与全文下载兜底不依赖新路线。

## Cookie 与访问边界

文献只在 HTTP 403 且 `Cf-Mitigated: challenge` 时尝试一次浏览器；失败进入短期冷却。保留原 PDF 类型/大小/内容验证。Cookie 不返回给模型、不写普通审计日志；私有临时结果正常退出/取消时删除，异常断电可能留下临时文件，不作为可重用 Cookie 缓存。

浏览器前后检查出口，Go 通过同代理再查询出口并比对，然后以同 UA、域隔离 CookieJar 请求文献。换代理配置会拒绝复用。需要**固定出口/粘性会话代理**；每连接轮换 IP 的代理无法靠前置探测保证下一条连接出口。出口核验服务不可达时拒绝复用，不降低校验放行。

不是完整浏览器工作台：当前工具是浏览器验证后 HTTP 提取网页文本，不提供点击/表单或完整动态 DOM 阅读；仅允许公开 HTTP(S) 入口、拒绝显式私网地址，尚非网络强沙箱（域名解析/页面子请求依赖可信代理和本地网络边界）。不使用个人浏览器资料，不保证所有 Cloudflare 站点通过。

## 网页读取与 TUN/Fake-IP

- 显式搜索模块代理仍优先，其次继承应用全局代理；代理已配置时不触发直连 DoH 兜底，也不失败后偷偷改直连。
- 未配置显式代理且域名解析为 198.18.0.0/15 时，网页工具通过固定 IP、正常 TLS 证书校验的 Cloudflare/Google DoH 查询真实公网 A 记录，再校验并连接该 IP，保留原域名 Host/SNI。DNS 只发送待访问域名，不发送网页路径、Cookie、Key 或正文；不更改系统 DNS/TUN。
- 保留网段不会直接放行，字面 Fake-IP、私有/本机地址及不安全重定向继续拒绝。DoH 不可用会提示配置代理软件的 HTTP/SOCKS 端口；当前不承诺所有 TUN 分流/IPv6-only 网站可用。
- 聊天“联网”开关冻结到每次 Run，关闭时隐藏内置搜索、网页与浏览器工具，并提示不得用其他工具绕过。不是对 Python/Shell/MCP 的 OS 级断网；自动科研文献流程不受聊天开关更改。
