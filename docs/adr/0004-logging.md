# ADR-004：日志使用 slog、脱敏 Handler 与有限轮转

- 状态：Accepted for P0
- 日期：2026-08-12

## 上下文

科研内容和密钥可能通过错误、HTTP 或 Tool 输出进入日志。桌面应用还需要控制长期磁盘占用。

## 候选方案

1. 直接输出控制台。
2. 使用 Go `slog`、JSONL、本地轮转和统一脱敏 Handler。
3. 引入第三方日志框架。

## 决定

P0 采用方案 2，避免额外依赖。日志字段和已知 Secret 在进入底层 Handler 前脱敏。

## 理由

- 标准库足以满足结构化日志。
- Handler 边界便于统一测试和后续注入 Secret 列表。
- 轮转限制诊断数据的磁盘占用。

## 负面影响

当前轮转器不支持跨进程并发写；SciAide 数据目录只允许单应用实例写入。生产前仍需完善单实例锁和日志保留策略。

## 重新评估条件

若出现多进程写日志、压缩归档或高吞吐需求，再评估成熟日志轮转库。
