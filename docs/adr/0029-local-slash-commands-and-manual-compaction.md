# ADR-0029：本地斜杠命令与手动会话压缩

## 上下文

SciAide 的模型、MCP、Skill、知识库和用量入口分散在侧栏与顶部。科研工作者在持续对话中需要一个稳定的键盘入口，但把 `/command` 直接作为 Prompt 交给模型会混淆本地操作、工具权限和普通研究文本。现有上下文压缩只在 Agent Loop 达到阈值时自动触发，没有用户显式执行的安全入口。

## 决定

1. 前端维护静态、受信任的 Slash Command Registry。仅当输入框完整内容精确等于已注册命令时执行本地动作；命令不支持任意字符串参数，不允许模型、Skill、MCP 或文档动态注册。
2. 输入 `/` 显示可过滤菜单，支持鼠标和上下方向键、Tab、Enter、Esc。未知命令或包含空白及其他文本的输入保持普通聊天语义。
3. `/mcp`、`/skill`、`/knowledge`、`/model` 和 `/usage` 默认进入运行时二级面板，而不是打开配置页；`/new` 和 `/help` 执行直接本地动作。以上操作不创建聊天 Message、Run、ToolCall 或 Approval。
4. `/mcp` 每次展开时调用脱敏的 `ListMCPServers`，把 `ready/degraded` 计为开启，把 `starting/initializing/stopping` 计为连接中，其余显示关闭。选择 Server 后按运行态读取 CapabilitySnapshot，展示 Tools/Resources/Prompts，并复用既有 Connect/Disconnect 生命周期；完整配置页仅作为显式管理入口。
5. `/skill` 合并已安装目录和当前项目具体版本关系；只有已启用、完整且可用的 Skill 可以向输入框插入 `$skill-id`。`/model` 直接更新当前会话模型选择，`/knowledge` 和 `/usage` 只显示已有后端事实；各自配置页仅由二级面板底部管理入口打开。
6. `/compact` 通过 Wails 调用 Agent Loop 的显式压缩方法。方法只接受会话 ID，自行读取最新 Run、模型和消息边界；非终态 Run 拒绝执行。
7. 手动压缩先校验最新 checkpoint，再以最新 Run 的 Assistant Message（缺失时为 User Message）作为固定目标，最多渐进执行三轮。每轮复用现有无工具科研摘要 Prompt、不可信 JSON 输入、revision、SHA256 和来源计数。
8. 压缩不删除原始消息或协议状态，模型用量累计到最近 Run。前端结果只包含 revision、消息边界、来源计数、轮次和是否完成，不返回摘要正文。

## 理由

- 静态精确匹配避免文件路径、公式和论文中的斜杠文本被误解释为本地权限动作。
- 本地导航不进入模型上下文，减少 Token、Prompt 注入面和对话噪声。
- MCP 菜单显示真实连接态和能力目录，用户无需打开管理页即可判断工具是否可用；Skill 和模型也能在对话流内完成选择。
- 复用自动压缩的事实源、摘要协议和持久化格式，避免形成第二套不兼容记忆系统。

## 负面影响

- 当前命令由前端静态注册，第三方 Skill/MCP 不能添加命令；MCP Capability 文本只用于显示，不能反向注册本地命令。
- `/compact` 会产生一次或多次真实模型调用及费用；极长历史超过三轮时需要再次执行。
- 手动压缩用量归入最近 Run，而不是单独的维护 Run。

## 重新评估条件

- 命令需要参数时，先设计类型化参数 Schema 和显式预览，不能直接执行任意尾随字符串。
- 若允许扩展包提供命令，必须增加独立命名空间、签名来源、冲突处理和权限声明，且默认不得获得执行能力。
- 引入独立维护任务模型后，可将手动压缩用量从最近 Run 拆分到专用审计记录。
