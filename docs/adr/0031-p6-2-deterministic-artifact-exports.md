# ADR 0031：Artifact 导出是确定性的不可变派生记录

## 背景

P6.1 已把正式科研产物收敛为不可变 ArtifactVersion。DOCX/PDF 是用于阅读和交付的版式派生物；如果把导出覆盖回原版本、把它伪装成新原件，或依赖系统 Word/浏览器打印，会破坏来源身份、跨机器复现和失败回滚。引用快照目前只有证据来源、定位、题名和原文，不包含完整作者、年份、期刊或 DOI。

## 决策

1. `ArtifactExport` 独立于 `ArtifactVersion`，绑定源版本、格式、引用样式、生成器版本、源 SHA256、导出 SHA256 和独立 Blob。导出不能更新，不能改变 `current_version_id`。
2. 同一源版本、格式、引用样式和生成器版本只能有一条记录。再次生成字节一致时复用；字节不一致时视为生成器非确定性并拒绝。
3. 导出先复制项目私有临时快照并校验源 SHA256，再生成、重新打开验证并发布内容寻址对象。下载使用临时文件、SHA256 复核和原子重命名，已有目标不覆盖。
4. DOCX 直接生成固定 OpenXML 结构；PDF 使用固定内嵌字体、固定元数据和稳定对象顺序。运行时不依赖 Word、LibreOffice、Chrome、系统字体或网络服务。
5. Markdown 通过 Goldmark GFM AST 转为结构块。PDF、DOCX、XLSX、CSV/TSV 复用本地解析器；结构预览限制块数、表格行列和文本长度。图片和不可提取二进制不能伪装成研究文档。
6. 正式引用只解析源 ArtifactVersion 的可信 Citation snapshot。GB/T 使用数字标号；APA 在作者/年份缺失时使用可用题名或来源与 `n.d.`，并明确披露缺失字段。正文伪造的 `[K-...]` 显示为未验证引用。
7. 正式导出必须包含可读正文且不能依赖解析器截断结果。宽表按固定上限分段，后续分段重复首列；DOCX 表头可跨页重复，PDF 超高行按页切片。改变确定性布局算法必须提升生成器版本，既有导出不得重写。

## 结果

- 原件身份、版本历史与派生交付物边界清晰，重命名 Artifact 不会改变历史版本的导出字节。
- 相同输入可以用 SHA256 验证复现，生成或下载失败不会覆盖原件和用户文件。
- 当前引用输出是可审计的有限格式化，不宣称具备完整 CSL 书目数据库能力。
- 空白扫描件不会生成只有标题和溯源的误导性报告；极宽或极高表格不会产生负宽度、页外绘制或静默丢字。
- 项目备份需要同时携带 ArtifactVersion、ArtifactExport、Blob 和 Manifest 关系，作为 P6.6 收尾的一部分设计；P6.3 先完成公共科研数据库 Connector。
