# ADR-0028：知识库任务运维、解析诊断与检索评测

## 上下文

P5.1～P5.5 已具备项目级索引、混合检索、可信引用和结构解析，但后台 ImportJob 只暴露粗粒度状态。用户无法区分等待、解析、向量化和提交，也无法显式取消、重试或重建单篇文档。解析成功也不等于提取质量可用，尤其是扫描型 PDF。检索实现缺少固定语料门槛，排序变化只能依赖人工体验发现。

## 决定

1. ImportJob 使用 `queued/loading/chunking/indexing/completed/failed/cancelled` 阶段，前端按确定性阶段映射进度，不伪造字节级或页级精确进度。
2. 用户可以取消排队或运行中的任务。用户取消持久化为 `cancelled` 并阻止当前 IndexVersion 的自动补建；应用关闭造成的上下文取消仍重新排队。失败或取消后的恢复必须由用户显式重试。
3. 单文档重建复用同一 IndexVersion，并在项目索引 SQLite 事务内整体替换该文档的 Document、Chunk、FTS 与向量记录。事务提交前继续提供旧索引；提交成功后使用独立、短超时上下文完成 ImportJob 与全局 Document 元数据。
4. 当项目已有 ready IndexVersion 时，搜索直接读取它，不等待后台队列排空。只有首次建库且没有任何 ready 版本时，搜索才同步推进队列并尝试激活首个版本。
5. Attachment 保存解析器返回的有界 Metadata。知识库据此生成 `good/warning/poor/unavailable` 诊断，覆盖 PDF 文本页、空页、平均文本量和截断，以及 DOCX 标题/表格、XLSX Sheet。诊断只表示提取可用性，不声明内容正确。
6. 扫描件不触发 OCR、模型下载或外部上传。无文本 PDF 明确提示当前未内置 OCR。
7. 仓库内固定语料分别运行 FTS5/BM25 和确定性 Embedding + RRF，计算 Hit Rate、Mean Recall、MRR 与 Locator Rate。当前门槛为命中率 100%、平均召回率 100%、MRR 不低于 0.95、来源定位率 100%。

## 理由

- 显式任务控制让长时间向量化可以取消和恢复，同时区分用户意图与进程中断。
- 事务替换和 ready 版本优先读取避免重建期间知识库不可用或暴露半成品。
- 解析诊断能在检索前发现扫描件、空页和严重缺字，但不会制造“解析成功等于事实正确”的错误保证。
- 固定离线语料让分词、分块、排序和融合策略的回归成为自动检查，而不是发布后的主观反馈。

## 负面影响

- 阶段进度是离散估计，不能表示大型文档当前已处理的准确页数。
- 同一 ready IndexVersion 内重建单文档时，索引文件仍会产生正常的 SQLite WAL 写入和短暂提交锁。
- 固定小语料只能阻止明显回归，不能代表所有学科、语言和真实论文分布。
- 没有 OCR 时，纯扫描 PDF 仍需要用户先通过外部工具生成文本层。

## 重新评估条件

- 解析器提供可靠的页级进度事件后，再将确定性阶段进度升级为真实进度。
- 固定语料扩展到真实授权数据集时，按领域拆分 Recall@K、nDCG 和延迟门槛。
- 未来若提供 OCR，只能作为用户显式启用的可替换 Adapter，并单独设计模型来源、体积、隐私和资源限制。
