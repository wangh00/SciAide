# ADR-0036：P7.2 使用项目级 Python 环境与持久 Kernel

- 状态：Accepted
- 日期：2026-08-25

## 上下文

一次性 Python 可以执行独立脚本，但不能稳定表达依赖版本、跨步骤分析状态、表格/图片结果或复现边界。直接复用系统 Python 会让项目互相污染；让 Skill 静默安装包会绕过审批；只限制 Workspace 路径又不能构成操作系统沙箱。

## 决定

1. 每个项目最多维护一个 SciAide 管理的虚拟环境。用户从宿主探测或手动选择的 Python 3 创建环境；应用记录解释器路径、版本、架构、文件 SHA256、锁定包、`pip freeze` SHA256 和环境指纹。
2. 环境创建、重建和安装在随机暂存目录完成，验证后原子替换已提交环境；项目级锁串行环境变更。启动恢复会中断遗留操作、清理暂存并根据已提交字节修复或标记环境损坏。
3. `pip install` 只允许通过高风险 `builtin.python.environment.install`，继续走 Policy、Approval 和审计。默认 Skill 只能声明依赖，不能静默安装或修改环境。
4. 每个项目使用一个串行持久 Kernel；变量和导入只在该进程生命周期内保留。用户、超时、取消、`MemoryError`、应用关闭、环境变化或 15 分钟空闲会停止 Kernel，重启后状态清空。
5. Kernel 在 Windows Job Object 内运行，默认限制进程树提交内存为 1 GiB。该限制不提供 CPU、文件系统或网络强隔离，不能把不可信代码当作安全负载运行。
6. 输入必须是当前 Workspace 常规文件，执行期间设为只读并在结束时复核 SHA256；声明输出必须新建于 `analysis-output/`。失败、取消、超时、输入变化和资源超限会删除声明输出及本轮图片，不产生半 Artifact。
7. 结果结构化保存 stdout、stderr、JSON 值、表格、异常和最多 16 张 Matplotlib PNG。代码、输入数据、输入文件、环境、输出或异常快照共同生成 `reproductionSha256`；它用于复核执行记录一致性，不证明科学结论正确。
8. Shell、一次性 Python 和 Kernel 的工具调用一旦获准即默认允许联网，不增加域名白名单或额外审批；依赖安装仍单独确认，模型 API Key、MCP Secret 和 Credential Manager 内容不注入子进程。

## 结果

- 科研分析可以在项目边界内保持状态、产生结构化结果并绑定稳定环境和输入输出哈希。
- 项目环境增加磁盘占用，且本机必须已有 Python 3；SciAide 不自动下载解释器。
- 默认联网减少配置，但获准代码仍可外传其能读取的数据，Plan 用户必须审查完整调用。

## 重新评估条件

- 引入 Conda、R、Julia、GPU 调度、容器、跨平台正式发布或真正的不可信代码沙箱。
- 需要多 Kernel 并行、离线依赖仓库或可移植的完整环境镜像。
