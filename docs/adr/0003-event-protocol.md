# ADR-003：内部事件 Envelope

- 状态：Accepted for P0
- 日期：2026-08-12

## 上下文

模型流、运行状态和索引进度需要从 Go 推送到 React。WebView 事件可能丢失、重复或乱序，UI 也不能成为事实来源。

## 候选方案

1. 每种事件发送任意 JSON，不设统一字段。
2. 使用带版本、事件 ID、聚合 ID 和序号的统一 Envelope。

## 决定

采用方案 2。关键事件先持久化再推送；UI 发现序号缺口时使用 Snapshot API 恢复。

## 理由

- 支持去重、排序、协议升级和故障诊断。
- 为后续 Run/RunEvent 崩溃恢复建立稳定基础。

## 负面影响

所有事件需要维护 Schema 和序号。

## 重新评估条件

若后续采用能够提供同等语义的成熟本地消息协议，可重新评估具体 Envelope 实现。
