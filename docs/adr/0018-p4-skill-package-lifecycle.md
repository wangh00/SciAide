# ADR-0018：P4 Skill 包安装生命周期

## 状态

Accepted（2026-08-14）

## 背景

Skill 包、Manifest、脚本和压缩包都属于不可信输入。P4.1 已建立版本化目录、严格解析和哈希持久化，但直接把文件复制到 `~/.sciaide/skills` 会产生路径穿越、压缩炸弹、半安装状态、启动时静默信任变更以及卸载误删等风险。

## 决策

1. P4.2 仅接受用户显式选择的本地文件夹或 ZIP；不连接在线市场，不下载依赖，也不执行包内脚本。
2. 文件夹先复制到 `cache/skill-staging`，ZIP 先完成条目预检再解压到随机暂存目录。暂存包通过与 P4.1 相同的 Manifest、UTF-8、大小、文件数、符号链接和全包哈希校验后才能进入安装目录。
3. ZIP 拒绝绝对路径、`..`、反斜杠、Windows 保留名、大小写重复路径、符号链接、非常规文件、加密条目、过深路径和声明/实际大小不一致。解压只使用 `O_EXCL` 创建普通文件。
4. 安装目录固定为 `skills/<id>/<semver>`。不同版本并存，项目启用关系固定到具体版本；回滚等价于显式选择一个已安装的更低版本。
5. 同版本不同内容默认拒绝。只有 `replaceExisting=true` 的显式操作才能替换，并先把旧目录原子移动到 `backups/skills/replaced`。
6. 原始 ZIP 或文件夹的确定性 ZIP 快照保存到 `backups/skills/packages/<id>/<version>/<sha256>.zip`。SQLite 只保存相对路径、来源类型、原文件名和 SHA256，不向前端返回本机归档路径。
7. 文件激活后再以单个 SQLite 事务接受可信哈希和来源；数据库写入失败时恢复旧目录或把新目录移入失败备份。启动目录扫描仍无权接受已记录版本的新哈希。
8. 卸载先把安装目录原子移动到 `backups/skills/uninstalled`，再删除数据库记录。仍被项目引用时默认拒绝；删除项目关联必须由用户显式选择。数据库删除失败时恢复目录。
9. 所有安装、刷新、项目版本切换和卸载操作在 Skill Service 内串行化。Skill 内容始终只是数据；后续 P4.3 注入上下文时仍不能越过 ToolRegistry、权限审批或 Workspace 边界。

## 结果

- 安装中断不会暴露可被启动扫描接受的半包。
- 原始来源、安装副本、暂存缓存和卸载/替换备份彼此分离。
- 版本升级和回滚可审计，卸载默认可恢复。
- 当前阶段不提供在线下载、签名发布者信任、自动更新、Skill 前端管理页或脚本执行；这些能力必须另行设计和验收。
