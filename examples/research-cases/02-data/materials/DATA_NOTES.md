# Wine Quality 输入说明

来源：UCI Wine Quality，Cortez、Cerdeira、Almeida、Matos、Reis（2009），DOI `10.24432/C56S3T`，CC BY 4.0。

研究对象为葡萄牙北部 Vinho Verde 葡萄酒。只分析原公开文件中的红葡萄酒；白葡萄酒原件保留在 sources，不混入本任务。质量分数来自专家感官评价，来源允许 0 到 10，有序且不均衡；不等于严格等间距的物理测量。

| 列 | 含义 | 用途 |
|---|---|---|
| sample_id | `red_0001` 形式的原数据行号，案例派生 | 追踪原行；不是真实酒样身份；不能作为预测特征 |
| split | 案例固定的 train/test 划分 | 只用来划分，不能作为预测特征 |
| fixed_acidity | 固定酸度 | 数值特征 |
| volatile_acidity | 挥发性酸度 | 数值特征 |
| citric_acid | 柠檬酸 | 数值特征 |
| residual_sugar | 残糖 | 数值特征 |
| chlorides | 氯化物 | 数值特征 |
| free_sulfur_dioxide | 游离二氧化硫 | 数值特征 |
| total_sulfur_dioxide | 总二氧化硫 | 数值特征 |
| density | 密度 | 数值特征 |
| pH | pH | 数值特征 |
| sulphates | 硫酸盐 | 数值特征 |
| alcohol | 酒精 | 数值特征 |
| quality | 原专家质量评分 | 目标变量 |

来源 API 与数据说明未给这些字段的完整单位定义，所以本包不补造单位。需要单位相关解释时应追加原始出处核实。

## 派生规则

- 原件用分号分隔；计算输入用逗号。表头空格改下划线，`pH` 大小写保留。所有实测值字符串原样保留，没有缩放、填补、去重或合成数据。
- initial 是红葡萄酒原文件前 1000 行；full 是全部 1599 行。原顺序**不声明为时间顺序**。首 1000 行也不声明为随机代表性子样本。
- 特征顺序为上表 11 个数值特征。逐行以原始特征值字符串按此顺序用 `|` 连接，计算 SHA256，取前 8 位十六进制转整数再 `% 5`；等于 0 为 test，否则为 train。quality 不参与划分。
- 同特征记录分在同侧，扩充后原记录的 split 不变。CSV 已提供 split，分析不要自行随机重分，也不要从 float 重建字符串哈希。
- 这是预先固定的近似 80/20 诊断划分，不是官方基准划分、交叉验证或外部验证。是否是同一酒样、同一批次无法从现有字段判断，同特征分组不能解决所有潜在相关性。

重复记录保留并报告，不凭字段相同就认定录入错误。推断时说明重复权重与非独立性局限，不把 Pearson 相关、回归系数解释为因果。
