# 科研模式真实材料案例包

准备日期：2026-09-30。这里提供实际输入，不只是三个提示词入口。论文与数据来自公开来源，方法参考代码为本案例编写。**材料准备及本地参考计算已验证，SciAide 真实模型端到端尚未验收。**

**公开仓库 / Release 包不附论文 PDF 或全文提取稿**，避免把公开可下载误当公开再分发许可；本地已经准备好的原件不删除。文献来源、版本和预期哈希见 [SOURCES.md](SOURCES.md) 与 `sources/source-manifest.json`。首次使用公开包，可执行 `python tools/download_papers.py` 从原作者/arXiv 下载并核对哈希，再安装 `pypdf`、执行 `python tools/prepare_sources.py` 生成逐页稿；网络失败或版本哈希变化会明确停止，不替换已有文件，也可从来源页自行下载。下载脚本的本地核验可用 `python tools/download_papers.py --verify-only`，不访问网络。

## 先测哪一条

建议先跑 **01 文献比较**：无需 Python，先看能否真正读原文、形成可定位的比较，再在同一对话补入第三篇论文。之后跑 **02 数据分析 → 03 方法源码续做 → 02 扩充数据**，检验实际计算和连续研究。

| 场景 | 上传的材料 | 可复制输入与步骤 | 应看到的变化 |
|---|---|---|---|
| 01 文献比较与补证 | Random Forests、XGBoost 全文；续做补 CatBoost | [01-literature/INPUTS.md](01-literature/INPUTS.md) | 从两篇到三篇的比较，原文定位、差异、不能直接比较的证据，保留旧稿 |
| 02 公开数据分析与扩充 | UCI 红葡萄酒首 1000 行；续做替换为全 1599 行 | [02-data/INPUTS.md](02-data/INPUTS.md) | 真实 Python 结果表、图、预测值与代码；数据确认前不变、确认后重新计算 |

02 和 03 是**同一科研任务的连续步骤**，不是两个相互独立的数据任务。测试通常共需新建两个科研任务（文献一个、数据一个），不需要新建 Codex 聊天。

## 程序里怎么开始

1. 打开当前 `build/bin/SciAide.exe`，建一个独立测试项目，选好自己的模型。**顶部「科研模式」→「研究方案」**，不是自由聊天里只问一句“比较论文”。
2. 文献案例：先用 **添加本地文献** 选 01 的 `materials/initial` 文件，再粘贴首次输入并 **生成研究路线**。
3. 数据案例：先粘贴 02 的首次输入生成计算路线，采用后在设置卡 **添加数据文件**，只选 02 的 initial CSV，然后开始执行。不要把 CSV 放进文献选择器。
4. 等待执行及审查，**先不登记产物**。后续都在该任务的原聊天输入框，用回形针添加指定 followup 文件，并实际发送追问；单纯选择文件不等于发送。
5. 补证、采用新方法、换数据需查看原确认卡。卡上文件或重算范围不符，先协商，不要确认。确认后才改变研究结果。

环境：01 无需 Python；02/03 需要项目 Python 与 `numpy`，图形通常需 `matplotlib`，AI 如选择 `pandas` 或其他包应说明依赖。模型与已授权工具可能联网；这是公开材料测试，不读取用户私有研究资料或自动使用模型密钥。

## 文件分工

- `materials`：真正供程序使用的输入。
- `INPUTS.md`：复制到程序的研究问题、追问和 UI 顺序；不是上传材料。
- `verification`：**留给你核对，不要上传给被测模型**。含文献核对点、数值参考、参考计算脚本和测试记录表。
- `sources`：原始数据 ZIP、未改动 CSV、数据说明、下载来源/版本/哈希。原始 CSV 是分号版，请上传 materials 中逗号版。
- `tools`：材料准备及真实解析器检查脚本，不是科研结果。

两篇 PDF 在 SciAide 当前解析器中有字体映射警告，所以附逐页 `.pages.txt` 提取稿。**PDF 与提取稿是同一篇文献，不是两项证据。** 提取稿不保真表格/公式，不是 OCR，也不能替代缺失文字的人工核对。原 PDF 保持下载字节未修改。
