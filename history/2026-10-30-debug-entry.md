## 3. 最近一次优化：2026-10-30（开发调试入口）

### 优化前

- 开发代理只能读取源代码/本地夹具，真实流程中的问题、路线和错误常需要用户重复点击后转述；缺少受限、可复用的真实服务调试入口。
- 一些非标准网关用 HTTP 200 返回独立额度错误标记，可能被当成正常完成或压缩摘要；上轮阶段阅读/提交优化和当时构建见[历史节选](2026-10-30-stage-protocol.md)。

### 优化后

- 开发 runner 在独立根装配原 Application，经固定本机 HTTP 动作复用原对话、问题/审批、规划采纳、Workflow 和诊断；代理可自行提交文本案例并推进，不借用户点击代替自测。生产桌面不启动此接口，操作唯一说明见[开发指南](../docs/development.md#科研流程调试入口)。
- 默认禁止模型调用；明确启用后每次 HTTP 外发前持久计数（含协商/重试/重定向），并有会话截止。来源模型只读，敏感设置在内存，本地只留脱敏 FK 占位；独立根策略绑定、OS 锁、Windows junction/硬链接和并发初始化均做保护。
- 初始创建必须预存 requestId；中断后显式重放找回原消息/Run或补初始化，不自动重跑。原 Plan 审批不放宽；派生规划继承冻结 Run 权限，采纳可能执行的 full 路线须服务器许可和每次确认。
- 已知独立额度标记走永久模型拒绝，不当正常答案、阶段完成或压缩检查点；最新讨论错误不能被旧规划成功遮盖。旧正式历史不追改成功，原科学检查和失败证据保留。
