### 优化后

- 仅未闭合事件遇 EOF 且 JSON 确为未结束时按原恢复预算重连；完整事件损坏、语法中段错误、类型错配和结构错误仍停止，不补字节、不接受残稿、不扩大预算。
- 损坏响应、原生流错误和 HTTP 200 协议解码失败仅保存安全元数据：字节数、SHA256、已知枚举、解码类别/字节位置及适用的事件边界；不直出上游消息、文本、工具参数、原生推理或任意 item ID。恢复审计重新验证元数据并保留可信 HTTP 状态。正常非 200 HTTP 错误仍沿既有合法 JSON 脱敏策略；旧历史不追溯改写。
- 原卡标明模型协议故障不是科学否决，指出重试阶段、保留仍有效成果和实现分件、网络流不续传、成功后继续后续阶段及可能费用。仍由用户显式点击，不新增自动请求或执行权限。
- 报告/独立审查新增一般性指导：候选记录、报告、独立研究和入选文档分开计数；合并须可追溯，真实漏项不能因披露局限而放行；派生比例的算术与分母、分析单位、外推有效性分别核对。不新增科学必填字段，不自动改报告或批准审查。
- 指导仅追加到新报告/审查执行，不改无关实现 prompt；保留 v1–v4 旧评估标记识别。独立差异复审提出的历史兼容、原生 Cause 和缓冲响应诊断问题均已修正。
