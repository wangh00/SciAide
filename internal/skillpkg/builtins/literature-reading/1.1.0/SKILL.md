# 文献阅读

以可复核证据为中心阅读论文。根据用户问题调整深度，不机械输出固定模板。

## 工作流程

1. 明确材料和任务：确认要分析的论文、用户关心的问题以及期望输出。用户提供项目附件时，先用附件列表和文档检查工具确认格式与可用定位符；用户指向普通 Workspace 文本时，再使用 Workspace 工具。只读取完成任务所需的内容。
2. 建立研究骨架：提取研究问题或假设、研究设计、样本与对照、变量或干预、主要结局、分析方法和关键结果。
3. 建立证据对应：把每个重要结论对应到材料中的数据、表格、章节或作者原话。区分“作者报告”“材料支持的解释”和“仍待验证的推断”。
4. 批判性检查：检查选择偏倚、测量偏倚、混杂、统计功效、多重比较、缺失数据、因果识别、外部效度和可重复性。只讨论与该研究设计有关的项目。
5. 回答用户问题：先给结论，再给证据和限制；最后列出最值得继续核验的问题或下一步阅读线索。

## 文档工具规则

- 大文档先检查结构或搜索，再按页、段落、工作表或行号读取，不要反复读取整份文档。
- PDF 引用使用解析工具返回的页码；Excel 引用使用 Sheet 和行号；DOCX 使用段落或表格单元定位符。
- 本地解析结果是检索辅助。涉及关键数值、公式、图表或版面含义时，明确建议用户回到原文件核验。
- 扫描 PDF 没有可提取文本时，明确说明当前需要 OCR，不把空白解析结果当成论文没有相关内容。

## 输出选择

- 快速解读：研究问题、方法、主要发现、一个关键限制。
- 深度阅读：按“问题 - 设计 - 结果 - 证据强度 - 局限 - 启示”组织。
- 多文献比较：统一比较维度，说明研究之间在人群、设计、结局和证据质量上的差异，避免直接合并不可比结论。
- 方法审查：优先分析设计是否能回答研究问题，再讨论统计模型和报告质量。

## 证据规则

- 不补造作者、期刊、年份、DOI、样本量、效应量、P 值、置信区间、页码或引文。
- 材料没有提供的信息标记为“材料中未找到”，不要用常识填空。
- 不把相关性写成因果，不把统计显著写成实际重要，也不把未拒绝零假设写成证明无效应。
- 引用材料时使用工具实际返回的文件名和定位符；没有定位依据时不要伪造精确位置。
- 对摘要、预印本、二手综述和完整论文采用不同证据强度，不把摘要中的简化表述当作完整方法证据。

保持术语准确，同时用科研初学者能理解的语言解释关键方法。不要展示隐藏推理过程，只呈现结论、依据和不确定性。
